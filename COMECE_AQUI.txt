🌿 COMO RODAR O PROJETO - RÁPIDO E FÁCIL
===========================================

## ⚡ 3 PASSOS SIMPLES:

### 1️⃣  SETUP (execute uma única vez)
```
Duplo clique em: setup_local.bat
```

### 2️⃣  RODAR A APLICAÇÃO
```
Duplo clique em: run_local.bat
```

Isso vai abrir 2 janelas automaticamente.

### 3️⃣  ACESSAR NO NAVEGADOR
```
http://localhost:3000
```

-----------

## 🔐 SE QUISER BAIXAR O DATASET DO KAGGLE:

1. Acesse: https://www.kaggle.com/settings/account
2. Clique em "Create New Token"
3. Coloque o arquivo em: C:\Users\SEU_USUARIO\.kaggle\kaggle.json
4. Execute: backend/download_dataset.bat

-----------

## ❓ PROBLEMAS?

Se tiver erro, verifique:
- Python 3.9+ instalado? → https://www.python.org/downloads/
- Node.js 18+ instalado? → https://nodejs.org/
- Ports 8000 e 3000 livres?
- Leia: EXECUTATION_GUIDE_PT_BR.md para mais detalhes
