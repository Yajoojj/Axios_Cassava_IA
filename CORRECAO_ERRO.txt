💡 EXPLICAÇÃO:

Python tem palavras-chave reservadas como:
- class
- def
- if
- for
- while
- etc.

Essas palavras não podem ser usadas como nomes de variáveis,
funções ou fields. Por isso mudamos para "classification"
que significa a mesma coisa e é um nome válido.
